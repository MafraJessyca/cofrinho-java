Cofrinho Digital — Java

Sistema de gerenciamento de moedas desenvolvido em Java como projeto acadêmico para aplicação de conceitos de Programação Orientada a Objetos.

Sobre o projeto

O sistema simula um cofrinho digital, permitindo adicionar, remover e listar moedas, além de calcular o valor total convertido para reais.

Funcionalidades
Adicionar moedas
Remover moedas
Listar moedas
Converter moedas para reais
Calcular o valor total armazenado

Tecnologias e conceitos
Java
Programação Orientada a Objetos
Herança
Polimorfismo
Abstração
Encapsulamento
ArrayList

Conversão
Para fins acadêmicos, foram utilizadas taxas fixas:
Euro: 1 × 6
Dólar: 1 × 5
Real: 1 × 1
